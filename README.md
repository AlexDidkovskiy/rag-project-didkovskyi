# rag-project-didkovskyi

Навчальний географічний RAG-довідник для студентів, які читають англомовні
джерела. Система має відповідати на короткі запитання англійською мовою за
географічними статтями Simple English Wikipedia, наводити ідентифікатори
використаних уривків і повідомляти про недостатність контексту.

Автор: **Олексій Дідковський**, група **ІПЗздм-26-1**.
Викладач: **Дашенков Д. С.**
Дисципліна: «Технології розробки гібридних систем штучного інтелекту», ХНУРЕ, 2026.

## Поточний етап

Лабораторна № 1 — попереднє проєктування. Підготовлено сценарій, вибір корпусу,
стек, архітектуру та структуру робочого простору. Модуль `src` зараз показує
конфігурацію проєкту; пошук і генерацію буде реалізовано в лабораторних № 3–4.

Головне джерело вимог — методичні вказівки кафедри ПІ ХНУРЕ 2026 року,
упорядник Дашенков Д. С. Карта вимог і сторінки першоджерела:
[docs/methodology.md](docs/methodology.md).

## Сценарій та дані

Приклад запиту: `What is the capital of France and which river flows through it?`
Належна відповідь містить тільки підтверджені знайденими уривками факти,
позначки на кшталт `[chunk_id]` і список джерел із URL. Якщо потрібної статті
немає в корпусі, система має повідомити про недостатність даних.

Проєктний обсяг — **1 000 документів** із
[`wikimedia/wikipedia`, `20231101.simple`](https://huggingface.co/datasets/wikimedia/wikipedia),
тематична підмножина географії. Один документ — одна стаття, а не один чанк.
Картка джерела зазначає CC BY-SA 3.0 та GFDL. Спосіб відбору, атрибуцію і
обмеження описано у [звіті](reports/lab-1/report.md). Завантаження, фіксація
фактичного складу та статистики корпусу належать до лабораторної № 2.

## Обраний стек

| Рішення | Вибір | Причина |
| --- | --- | --- |
| Мова | Python 3.11–3.12 | Є бібліотеки для даних, моделей та CLI; TOML читається стандартною бібліотекою. |
| Векторне сховище | Chroma, локальний `PersistentClient` | Зберігає вектори й метадані на диску без окремого сервера. |
| Ембединги | `sentence-transformers/all-MiniLM-L6-v2` | Компактна англомовна модель, 384 виміри; придатна для CPU. |
| Генерація | Ollama + `llama3.2:3b` | Локальний запуск без платного API; використання за Llama 3.2 Community License. |

Для наступних етапів передбачено BM25 (`rank-bm25`), злиття RRF та перевірку
ідентифікаторів цитат. Початкові параметри: [config/project.toml](config/project.toml).
Це проєктні параметри, результати вимірювань ще не отримано.

## Встановлення та запуск

### 1. Отримати проєкт і створити середовище

Потрібні Git, Python 3.11 або 3.12 та модуль `venv`.
На Debian/Ubuntu їх можна встановити пакетами `git python3 python3-venv`.

```bash
git clone https://github.com/AlexDidkovskiy/rag-project-didkovskyi.git
cd rag-project-didkovskyi
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Запустити матеріали першої лабораторної

Команда працює без завантаження корпусу, моделей і сторонніх бібліотек:

```bash
python -m src --show-config
```

Виводиться JSON із проєктними рішеннями. Це перевірка читання конфігурації.
Архітектуру можна переглянути у [Mermaid-діаграмі](reports/lab-1/architecture.md),
звіт — у [PDF](reports/lab-1/report.pdf).

### 3. Встановити бібліотеки обраного стеку

Цей крок готує середовище для лабораторних № 2–4:

```bash
python -m pip install -r requirements.txt
```

У `requirements.txt` зафіксовано сумісні діапазони версій. Фактичні встановлені
версії потрібно записати під час реалізації; це не lock-файл із результатом
перевіреної інсталяції всього стеку.

### 4. Встановити і запустити генеративну модель

Встановити Ollama за [офіційною інструкцією для Linux](https://docs.ollama.com/linux).
У першому терміналі запустити сервер, якщо його ще не запущено службою:

```bash
ollama serve
```

В іншому терміналі:

```bash
ollama pull llama3.2:3b
ollama run llama3.2:3b "Explain what a river is in two sentences."
```

Стандартний URL сервера — `http://localhost:11434`. Остання команда перевіряє
саму модель; повний цикл RAG з'явиться в лабораторній № 4. Первинне завантаження
потребує інтернету. Планується робота на CPU; швидкодію буде виміряно пізніше.

reports/lab-1/report.pdf          PDF для подання на DL

## Звіт та фіксація версії

Звіт оформлено українською мовою: Times New Roman 14 пт, міжрядковий інтервал
1,5; абзац 1,25 см; поля 30/15/20/20 мм; номер сторінки внизу праворуч із другої.
Редагувати текст потрібно у `reports/lab-1/report.md`.

Для відтворення PDF потрібні ReportLab і локально встановлені файли
Times New Roman (`Times.TTF`, `Timesbd.TTF`). Файли шрифту не поширюються в Git.

```bash
python -m pip install -r requirements-report.txt
python tools/build_report.py --font-dir /path/to/times-new-roman
```

Реліз першої лабораторної: [тег lab-1](https://github.com/AlexDidkovskiy/rag-project-didkovskyi/tree/lab-1).
Послідовність фіксації після завершення матеріалів:

```bash
git add README.md AGENTS.md .gitignore requirements.txt requirements-report.txt config docs reports src tools
git commit -m "Prepare laboratory 1 RAG system design"
git tag lab-1
git push origin main
git push origin lab-1
```

PDF необхідно завантажити на DL перед захистом. Самої наявності файлу в GitHub
за методичкою недостатньо для подання роботи на перевірку.
